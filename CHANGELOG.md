# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-05-30

### Added

- Initial public release of Huiyu PiwebUI Forge
- Custom dark/light theme system with CSS variable support
- Project management with multi-project workspace support
- Session management with branching, archiving, and search
- File browser with CodeMirror editor (10+ language support)
- Integrated terminal with multi-tab and reconnect support
- Git integration with hunk-level staging and git-graph
- MCP (Model Context Protocol) support with global and project-level config
- PWA support — installable on desktop and mobile
- Responsive mobile UI with drawer navigation
- Quick Actions for common tasks
- Webhook and orchestration support
- Docker, docker-compose, Kubernetes, and OpenShift deployment support
- Authentication via JWT + API Key

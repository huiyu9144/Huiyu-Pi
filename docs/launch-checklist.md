## 六、你的核心卖点（推广文案）

### 一句话介绍
> A self-hosted AI coding agent with near-zero context, supporting Claude, GPT, DeepSeek, and more.

### 中文一句话
> 一个本地开源的 AI 编程助手，上下文接近零，速度比 Codex/Claude Code 快数倍。

### 三大差异化
1. **零上下文** — 不像其他工具加载整个代码库，我们保持上下文最小化
2. **完全自托管** — 代码、密钥、对话全在本地，无数据泄露
3. **多 LLM 支持** — Claude/GPT/DeepSeek/Gemini/Mistral 一键切换

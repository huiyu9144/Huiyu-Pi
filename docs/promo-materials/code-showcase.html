Huiyu Pi
一行命令，即刻启动
Terminal
1 # 无需安装，一行命令启动
2 $ npx huiyu-pi
3 🚀 Huiyu Pi v1.1.0 starting...
4 📡 Server running at http://localhost:9144
5
6 # 或全局安装（后续启动更快）
7 $ npm install -g huiyu-pi
8 $ huiyu-pi
9
10 # 自定义端口和工作目录
11 $ huiyu-pi --port 4000 --workspace-path ~/Code
12
13 # Docker 部署
14 $ docker-compose up -d

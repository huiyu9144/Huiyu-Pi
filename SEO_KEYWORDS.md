## Product Overview

### What is Pi?

[Pi](https://github.com/topics/pi) is a lightweight, open-source coding agent that operates directly in your terminal. It uses a **minimal default context** — only the most essential commands like screenshot capture — keeping the AI's attention focused and responses blazing fast. Pi is the engine: powerful, lean, and extensible.

### What is Pi-forge?

[Pi-forge](https://github.com/topics/pi-forge) is the skill framework for Pi. It lets you author and compose custom agent skills — think of it as a forge where you craft your agent's capabilities. However, pi-forge's interaction experience is terminal-based, which leaves room for a more polished visual interface.

### Why Huiyu Pi?

Pi is excellent but **lacks a frontend WebUI**. Pi-forge is powerful but some interaction details are inconvenient for daily use.

I built **Huiyu Pi** primarily **for myself** — because I wanted a web-based agent that feels **fast, smooth, and natural**. I use it every day and it's genuinely a joy to work with. It's so good that I decided to **share it with everyone**.

> Building your own Harness and Agent from scratch is **way cooler** than using Codex or Claude Code.  
> I believe the future doesn't need centralized platforms. In the future, **everyone will have their own Harness system**.

### 1. Faster Performance — Compared to Codex & Claude Code

| Factor | Codex / Claude Code | Huiyu Pi |
|--------|-------------------|----------|
| Default context + prompt | ~20K tokens | **Near zero** |
| AI response latency | High | **Dramatically reduced** |
| Token consumption | High | **Massively reduced** |

By stripping away the bloated default context and keeping only the most essential commands (e.g., screenshot capture), Huiyu Pi delivers **dramatically faster AI responses** with far less latency.

### 2. Lower Token Consumption

Traditional IDE-based AI tools ship with **hundreds of rarely-used context builders**. Every command carries overhead. Huiyu Pi removes nearly all of them:

- No unnecessary system prompts
- No redundant tool definitions
- Only the context you actually need

**Result**: Token consumption drops substantially. Say goodbye to the era where "one sentence costs one dollar."

### 3. Pure Web — Much Faster

Traditional IDEs are **heavy client applications**:

- They slow down over time
- Memory usage grows
- Session switching is sluggish

Huiyu Pi is **pure web**:

- Instant session switching
- Minimal memory footprint
- No client bloat

### 4. Local Deployment — 100% Secure

Huiyu Pi runs **entirely on your local machine**:

- No data leaves your computer
- API keys stay local
- Zero network dependencies for sensitive data
- Full privacy control

### 5. Build Your Own Harness & Agent from Scratch

Forget about **bloated, unmodifiable platforms**. With Huiyu Pi:

- You own everything
- You customize everything
- You build your own AI empire

Building from scratch is **more powerful, more flexible, and way cooler** than using any closed platform.

### 6. Built on Pi & Pi-forge — The Best of Both Worlds

Huiyu Pi is **built on the shoulders of Pi and pi-forge**:

- Uses Pi as the agent engine
- Leverages pi-forge's skill framework
- **Adds a polished WebUI** that Pi never had
- **Fixes interaction friction** that pi-forge's terminal interface has

I built it for myself. It feels **incredibly fast and smooth to use**. Now I'm sharing it with you.

Huiyu Pi embraces **context minimalism**:

- Less noise → Better focus
